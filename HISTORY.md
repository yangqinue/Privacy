# History

## pilot-v1 (git tag `pilot-v1`)

The first complete round of the project: dataset v1 and the pilot analysis built on it. It is frozen; later work
starts from a regenerated dataset. Restore everything with `git checkout pilot-v1` (or `git worktree add ../pilot-v1 pilot-v1`).

**Dataset v1** (`data/`): 300 synthetic personas (p003-p302), 50 per age group, reference date 2026-10-01;
16 memory items each (one has 22), one templated year-anchored memory per persona; 6 activities with catalogs and tasks;
splits shadow_train 150 / dev 30 / test 120 (by group, age-stratified). Generated by `scripts/generate_dataset.py`
in several passes before version control (see the paper appendix draft for the history), so the files, not a re-run,
are the reference.

**Experiments** (`runs/`), all on the concert-ticket activity, model qwen3:32b (digest 030ee887880f):

| folder | what | size |
|---|---|---|
| `pilot_v0_nothink`, `pilot` | pipeline pilots, 12 personas, benign/adaptive | 24 dialogues each |
| `dev_v1` | benign/fixed/adaptive, 1 seed, uncalibrated, log loss primary | 90 dialogues |
| `dev_v2` | shared opening, agent-confirmed booking, enforced probing budget, shadow calibration (T=5.28), RPS primary; 3 seeds | 270 + 180 shadow |
| `dev_v3` | seeded adaptive mode, 3 seeds; v3 re-judge of dev_v2; other-attribute disclosure | 90 dialogues |
| `synthpai_infer` | age inferencer checked on SynthPAI (299/300 users) | - |

**Main findings (dev split, 30 personas, 360 dialogues)**: benign service leaks no measurable age information;
probing lowers RPS of the true group by about 0.02 (CI excludes zero for both adaptive modes) and raises within-one
accuracy from 0.51 to 0.71-0.73; year-anchored memories were elicited in 13-20% of probed dialogues, always after a
question about the past; adaptivity does not beat a good fixed question; stored household and work facts are stated
in 97% and 83% of fixed-probe dialogues. The inferencer reaches 58% within-5-years on SynthPAI's human-verified set
(GPT-4: 69.4%) and underestimates older users.

**Known limitations that motivate v2**: the year-anchored memory is inserted by template (one per persona), so the
"leakage concentrates in dated memories" finding is partly by construction; lifestyle traits are independent of age
and of work/household (internally inconsistent profiles); a single location; no gender, income or education; household,
work and health are stated verbatim in memory; one activity evaluated; the same model plays all roles.

**Not in git**: `logs/` (local run logs), `external/` (third-party data, e.g. SynthPAI), and the paper draft in
`../Privacy-Paper`, whose numbers and figures come from this tag.
